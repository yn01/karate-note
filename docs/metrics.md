# 開発の計測（見積もりと実績）

自作ハーネス（dev-forge、dev-gate、forge-ledger、jev-dispatch）を使った開発で、どれだけ速く・確かに作れたかを記録する。数字は動画とREADMEで使う。

## 測り方

- **見積もり**：PERT三点見積もり。楽観O・最可能M・悲観Pを時間で出し、見積もり＝(O＋4M＋P)÷6。
- **見積もりの前提**：Next.js/TypeScriptに慣れた中級エンジニアが、AIを使わずに手で実装する場合。
- **見積もりの出し方**：Claude Codeが下の「見積もりの目安」に照らして提案し、作者が確認してから記録する。始めた後に見積もりは変えない。
- **実績**：タスクの開始から終了までの経過時間。作者が申告した中断（食事・離席など）は除く。
- **レビュー指摘**：レビュー役のサブエージェントが、マージ前に見つけた問題の件数（不具合・原則違反・安全）。
- **モデルの使い分け**：jev-dispatch が選んだモデルの割合（期間の最後に集計）。
- **コスト**：Anthropic Console の利用額（期間の最後に確認）。
