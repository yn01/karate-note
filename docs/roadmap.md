# ロードマップ（MVP のあと）

ハッカソン（〜11/8 20:00）で作る範囲は [requirements.md](requirements.md) の MVP。ここには、MVP に入れないものと、入れるかを検討した機能をまとめる。思いついたら足していく。

## 1. 検討した機能（11/4 時点）

| 機能 | 判断 | 理由 |
| --- | --- | --- |
| アプリを開いたときのスプラッシュ（アプリ名と空手ノートの良さが伝わる画面） | **MVP に入れる（小さく）** | 審査員が最初に見る画面で、動画の冒頭にも使える。表示だけで小さく作れる。T11（仕上げ）で入れる |
| 道場生の目標の入力と表示（その年の目標） | **MVP に入れる（小さく）** | 「目標は道場生本人のもの」（プレーヤーズセンタード）をいちばん直接に見せられる。育成計画の「本人の目標」はもう DB にあるので、ホームに出して本人が直せるようにするだけで済む。T10（次のテーマ）と一緒に作る |
| 挙動ごとのイラスト | **MVP は最小限、残りはロードマップ** | お便りの「手本」（予備動作あり・なしのイラスト）は plan.md でもともと MVP に入っている。MVP では受けの前の1場面の2枚だけを作る。全挙動のイラストと、自主練・お便りからの使い方はロードマップ（下の2章） |
| ログイン（道場生・保護者・先生ごとの画面と機能） | ロードマップ | 審査員がログインなしで3つの立場を触れるデモにしている（README に明記）。実運用には必須 |
| カレンダー（過去のノート・ふりかえりを見返す） | ロードマップ | MVP は「今週の1冊」を通しで見せることに集中する。DB には日付つきで残っているので、あとから画面を足せる |
| 審査予定の設定（先生だけが設定） | ロードマップ | MVP では育成計画のマイルストーン（2027年2月の審査）から次の審査を出している。先生が進み具合を見て決める画面は、ログイン（先生だけが設定できる）とセットで作る |
| 取り込んだノート・入力したノートの編集 | ロードマップ（一部は MVP にある） | いまは保存の前に本人が確かめて直せる。保存したあとは、同じ日をもう一度取り込むと上書きされる（先生が承認した日は書きかえない）。保存したノートを開いて直す画面は、カレンダーと一緒に作る |

## 2. ロードマップ

### すぐ次に（実運用の前に必要なもの）
- **ログインと立場ごとの画面**：道場生・保護者・先生がそれぞれログインし、自分の画面だけを見る。保護者は自分の子どものお便りだけ、道場生は自分のノートだけ。
- **同意とプライバシー**：本人と保護者の同意を取る画面。1対1の文字起こしを整理のあとに消す・短く保つ。端末の中だけで文字にできる音声認識（オンデバイス）を使う。
- **呼び出しの回数制限**：人ごと・端末ごとの回数制限（いまは1日の上限と場面ごとの上限だけ）。

### 道場生と保護者の使いやすさ
- **カレンダー**：過去のノート・問いかけのまとめ・お便りを日付で見返す（道場生・保護者・先生）。同じ反省が続いていることに、本人が自分で気づけるようにする。
- **ノートの編集**：保存したノートを開いて直す。先生が承認した日のノートは、直したら先生に知らせる。
- **目標の見返し**：年の目標と、黒帯への道のりの上での今の位置を、ふりかえりのたびに見られるようにする。

### 先生の道具
- **審査予定の設定**：先生が道場生ごとに次の審査（いつ・何級）を決め、黒帯への道のりと育成計画のマイルストーンに反映する。
- **道場生一覧の強化**：未確認のノート、審査の予定、今期の重点を一覧で見る。
- **知見をためる仕組み**：承認するときの先生の直しや気づきを、skills の知見に足していく。
- **Managed Agents で道場生ごとの記憶**：道場生ごとの長い経過を踏まえた下書き。

### 手本（イラスト・動画）
- **挙動ごとのイラスト**：先生の平安二段の動画・スクショから、挙動ごとのイラストを作る（写真は個人情報の観点から使わない）。skills/kata/heian-nidan.md の「各挙動のポイント」とつなぐ。
  - 使い方の案：お便りの「今週見てほしいところ」に、その挙動のイラストを添える／自主練メニューに添える／問いかけで「どの挙動のことかな？」と本人が選べるようにする。
  - 作り方の検討：画像生成のツールで作る場合、先生の姿が特定できない線画にする。生成したものは先生が確かめてから使う。
- **手本動画と時刻**：先生の動画と各挙動のポイントを時刻でつなぎ、「2挙動目（0:08）」のように飛べるようにする（動画の解析はしない。動画は公開リポジトリに入れない）。

### 知見と対象の広がり
- 平安二段以外の形の知見（skills/kata/ のほかのファイル）。
- 基本と組手の知見。
- 大会ノート。
- 複数の道場生の分析（いまの一覧は表示だけ）。
- 横展開：地域のスポーツクラブ、職場の新人育成。
