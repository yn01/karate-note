## 動画（T13）を Claude で作る

外部の編集ツールの代わりに、Claude Code でコードから動画を作る。

- **作り方（案）**：[Remotion](https://www.remotion.dev/)（React で動画を書き、mp4 を書き出す）を使う。Claude がカットの構成、テロップ、図解（黒帯への道のり・Claude を呼ぶ5場面・承認の流れ）、画面収録の配置を書く。
- **素材**：capture-list.md の画面収録とスクショ。リポジトリの外のフォルダ（例：~/Dev/karate-note-video/assets/）に置く。動画と素材は公開リポジトリに入れない（CLAUDE.md）。
- **長さ**：3分以内（目標 2分57秒）。冒頭に「※道場生・保護者は架空の人物です」「※デモでは指導者の声のみ」のテロップを入れる。
- **声**：テロップ中心にする。ナレーションを入れる場合は作者が録音する。
- **決めること**：動画のプロジェクトをリポジトリの中（video/、素材は除外）に置くか外に置くか。T13 の計画のときに決める。
- **ライセンス**：Remotion は独自ライセンス（個人は無料、一定規模以上の企業は有料）。T13 の計画のときに個人利用で無料の範囲か確かめ、README の利用ライブラリに書く。
- **準備**：Remotion は書き出し用の部品を自分で持つので、ffmpeg を別に入れなくてよい見込み。T13 の前に動作を一度確かめる。
